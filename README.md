# BLOSTOM

ブロックを積んでロボットを組み、そのロボットで戦うゲーム。

胴体にブロックを貼り、関節（ボーン）を生やして腕や脚を作り、武器やスラスターの
プレートを貼る。できた機体はそのまま戦える。**脚の数も、重さも、武器の組み合わせも
自由**で、そのすべてが実際の動きに出る — 20トンの二脚と277トンの四脚では、歩き出す
速さも、曲がり方も、撃たれたときの揺れ方も違う。

デスクトップアプリです。

```bash
npm install
npm run game
```

## 1. 4つの画面

| 画面 | 何をするところ |
|---|---|
| **タイトル** | 入口。組んだ機体がここに立つ |
| **エディタ** | ブロックとボーンで機体を組み、プレートを貼る |
| **テストフィールド** | ルールなしの練習場。動きを確かめる |
| **ソロプレイ** | 7ステージを順に上がる本番。残機がある |

エディタとテストフィールドは上部バーのボタンで往復できる。ソロプレイは
**SORTIE 画面**（出撃準備）を通って入る。

## 2. 操作

| | |
|---|---|
| `W A S D` | 移動（**A が右 / D が左**：機体の前方から見た向き） |
| 移動キーを2回押し | **ダッシュ**。前後左右どこへでも。EN は使わない |
| `Space` | 上昇 / 接地中はジャンプ。押しっぱなしで飛行 |
| `左Shift` | 下降 |
| `E` | ブースト（ブーストプレートが要る。EN を使う） |
| 左クリック | 撃つ |
| `C` / `X` | 武器を切り替える |
| `F` | ロックオン |
| `←` `→` | ロックする相手を変える |
| 右ドラッグ | カメラを回す |
| `Esc` | 一時停止 |

キーはすべて割り当て直せる（タイトル →「キー設定」、または一時停止画面から）。

### EN（エナジー）

飛行とブーストが使う。**歩いている間はすぐ回復する**が、**推進器を焚いている間は
回復しない** — だから「今ここで使うか」が毎回の判断になる。地上でブーストを
押しっぱなしにすると2.4秒で空になり、歩いて4秒でほぼ全快する。

ダッシュは EN を使わない。使えなくなった機体が回避もできなくなるのは、その2つが
最も必要な瞬間だから。

## 3. ソロプレイ

**7つのステージを順に上がる。** 全20ウェーブ。ステージが変わるたびに戦う場所が
変わり、遮蔽の量も、見通せる距離も、重力までも変わる。残機とスコアは持ち越し、
ウェーブ番号もリセットされない。

出撃前に **SORTIE 画面**が開く。ここで決めるのは3つ:

- **どの機体で出るか** — 編集中のもの、保存したもの、収録機体20種から選ぶ
- **難易度** — 5段階
- 行き先（7ステージ）と、自分の機体の HULL / 質量 / 機動 / 武器数の確認

武器を積んでいない、ブーストがない、脚もフロートもない — そういう機体はここで
警告が出る。ウェーブ1で気づくには遅い。

### 難易度

5段階の違いは主に**上がり方の速さ**。最初の強さはどれも近く、終盤がまったく違う。
敵の強さは1つの数字で、ウェーブとともに上がる（画面に `×2.1` のように出る）。
耐久と与ダメージの両方が上がる。

| | 序盤 | 中盤 | 終盤 | 残機 | スコア |
|---|---|---|---|---|---|
| EASY | ×0.7 | ×1.0 | ×1.3 | 5 | 0.6倍 |
| NORMAL | ×1.0 | ×1.5 | ×2.1 | 3 | 1.0倍 |
| HARD | ×1.3 | ×2.1 | ×3.1 | 3 | 1.6倍 |
| SUPER HARD | ×1.6 | ×2.8 | ×4.2 | 2 | 2.4倍 |
| HELL | ×1.9 | ×3.7 | ×5.7 | 1 | 4.0倍 |

### ウェーブの合間

ウェーブを抜けるたびに3つから1つ選ぶ。`REPAIR`（装甲45%回復）/
`REARM`（全弾補充＋15%回復）/ `RESERVE`（残機+1）。

## 4. 機体を組む

### 置く

ツールを選んで、置きたい場所をクリックするだけ。

| | |
|---|---|
| 面をクリック | その面にぴったり付く。押した位置に付く |
| 何もない所をクリック | 空中に浮かせて置く（`Shift+ホイール` で高さ） |
| `R` | 置く前に向きを90°回す |
| ドラッグ | 同じ列に連続で置く |
| `Alt+クリック` | そのパーツの形・寸法・色を写し取る |
| 右クリック | カーソルの下のパーツを削除 |

**左右対称は既定でオン。** 片側に置けば反対側にも付く。置く前にゴーストで
両方見える。

### 動かす

ボーン（関節）を挟むと、その先が動くようになる。5種類:

| | |
|---|---|
| レッグボーン | 歩調に合わせて振れる。脚 |
| アームボーン | 歩調の逆位相で振れる。腕 |
| フェイスボーン | 進行方向を向く。頭やセンサー |
| カスタムボーン | 波形・軸・速さを自分で決める。腰のひねり、プロペラ、レーダー |
| ウェポンボーン | 決めた武器を持っている間だけ構える。持ち替えた瞬間だけ動く |

**肩・膝・腰のような関節は、ボーンの種類ではなく「効き」と「ずらし」で作る。**
効きは0で固定・1で標準・2で大振り、ずらしは歩調1周のうちいつ動くか。先端ほど
遅らせるとしなる。可動域は前と後ろで別々に決められるので、膝は前にだけ深く曲がる。

カスタムボーンは歩き方だけでなく、**ブースト・着地・発砲・被弾・耐久・EN・武器切替**
でも動かせる。インスペクタの `動作テスト` から、編集画面でも走らせて確かめられる。

### ミニマップ

画面右上に、アリーナを真上から見た円盤が出る。**機首が常に上**で、
自分は真ん中に固定され、世界のほうが回る（知りたいのはいつも
「正面に何があるか」で、「北はどっち」ではないため）。

床の遮蔽は塗りつぶし、空中のものは中抜き、敵は赤、ロック中は黄。

### 音と見た目

床や岩の表面、金属が映す夜空、宇宙と月の空、発砲・着弾・噴射のエフェクト、
効果音は、外部の公開素材を同梱している（合計 3.8MB）。
出どころはゲーム内の「使い方 → クレジット」と [LICENSES.md](LICENSES.md) に全部ある。

`public/kit/` を消しても動く。その場合はすべて手続き生成に戻る。

### 削る

ブロックは中身をボクセルで持っていて、削る・盛る・塗るができる。丸いブラシと
四角いブラシ、左右対称に削るモードがある。削った分だけ軽くなる。

### 貼る

装備プレート。武器（丸）とシステム（四角）がある。

**貼る場所が効く。** ブーストは炎がプレートから出るので、後ろに貼れば前へ、下に
貼れば上へ進む。ローリングは貼った面の向きが回転軸になる。サークルは貼った場所を
中心に円線を描き、**その線に触れているパーツ**が線に沿って回る。

## 5. 収録内容

### 戦う場所（7）

| | 重力 | どういう場所か |
|---|---|---|
| 演習場 | 22 | 広く見通しがよい。基準になる場所 |
| 市街地 | 22 | 高い建物が密。撃ち合いは短く、角の取り合い |
| 廃工場 | 22 | 低い遮蔽が一面に。撃ってすぐ移る |
| 峡谷 | 22 | 遮蔽が少なく距離が出る。長射程が効く |
| 塩湖 | 22 | ほぼ何もない。避けるしかない |
| 宇宙 | **0** | 足場のない広い空間。止まるのも噴射しだい |
| 月 | **1.6** | 一跳びで建物を越え、落ちてくるまでが長い |

### 収録機体（20）

5階級。質量で **3.7 〜 277**、身長で **1.4m 〜 19.7m**。

| 階級 | 機体 |
|---|---|
| 極小 | GNAT / MITE / SPARK / TICK |
| 小型 | POGO / DART / SCARAB / PIP |
| 中型 | STRIDER / CRAWLER / FUNNEL / LANCE / TURTLE |
| 大型 | TITAN / SPIDER / HAULER / WYVERN |
| 超大型 | COLOSSUS / LEVIATHAN / FORTRESS |

エディタの出発点にもなり、ソロプレイの相手としても出てくる。序盤のウェーブは極小、
終盤は超大型が先頭に立つ。

### 武器

ビーム / ガトリング / ショット / ブレード / ミサイル / スナイパー / レーザー /
スプレッド / マグナム / グレネード。射程・弾速・連射・弾数がそれぞれ違い、
**同時に積めるのは4枚まで**。

**弾は速すぎない。** どれも25mを渡るのに0.1秒以上かかる — 見えない弾は避けられない。
ロックオンも交差点を厳密には解かない。**動き続けている機体には当たらない**、が
戦闘の前提。

### システムプレート

ブースト / フロート / グラビティ / ローリング / サークル / シールド /
エナジータンク。グラビティとフロートは正反対なので同時には付かない。

## 6. 開発

```bash
npm install

npm run game     # 起動する（配信と同じ形）
npm run dev      # 開発サーバ。別窓で `npm run game:dev` が繋ぎに来る

npm run check    # lint + 訳の欠け + 単体テスト。これが通ればだいたい大丈夫
npm test         # 1,214件。約40秒
npm run smoke    # 実物のシェルで69項目。起動・描画・入力・リプレイの決定性
npm run pack           # electron-builder で .exe を作る
npm run smoke:packaged # 作った .exe が起動するか（asar 込みの本番構成）

npm run lint
npm run i18n:check     # src の文字列で英訳が無いものを挙げる
npm run bake:icon      # アイコンを描き直す（tools/bake-icon.py）
```

CI（`.github/workflows/ci.yml`）が push ごとに lint・訳・テスト・スモーク・
パッケージ起動の5つを回します。

**ブラウザ実行は廃止しています。** Electron が唯一の実行形態です。

### ディレクトリ

| | |
|---|---|
| `src/core/` | 機体のデータモデル（Assembly / Rig / VoxelBlock / Presets） |
| `src/zmf/` | 運動モデル。`ZMF (ZOE Motion Framework) Core v1.0.0` の実装 |
| `src/game/` | 戦闘（FieldScene / Weapons / Robot / SoloRun / World / Arenas） |
| `src/editor/` | エディタ |
| `src/ui/` | 画面 |
| `src/anim/` | 見た目の動き |

### テストの考え方

- **`npm test`（1,214件）** — ルールのあるものすべて。ブラウザなしで約40秒
- **`npm run smoke`（69件）** — Node では届かないものだけ。実際に WebGL が描くか、
  実際のポインタイベントがエディタに届くか、20機のプリセットが本当に立つか、
  記録した試合を2回再生して同じ状態ハッシュになるか
- **`npm run smoke:packaged`** — electron-builder が作った .exe が起動するか。
  上の2つとは別の問いで、パッケージング固有の欠落はここでしか見つからない

かつて447件のブラウザスイートがあり、2分から20分かかって時々レンダラごと落ちた。
それが覆っていて Vitest で書けないものは4つしかなかったので、その4つだけを残した。

## 設定と言語

タイトル画面の **「設定」** から:

| | |
|---|---|
| **言語** | 日本語 / English。切り替えると画面を作り直します |
| **音** | 全体・音楽・効果音、それぞれの音量と消音 |
| **画質** | 軽い / ふつう / きれい（影・にじみ・MSAA・描画倍率）。フレームレート表示 |
| **読みやすさ** | 文字の大きさ 85〜160%、動きを抑える（OSの設定に従う / 強制） |
| **操作** | マウス感度、上下反転、横移動反転 |

キーの割り当ては **「キー設定」** から。編集画面のツールキーもここで変えられます。
ゲームパッドは挿せば使えます（設定不要、キーボードと同時に生きています）。

英訳は `src/ui/strings/` にあり、**キーは日本語の原文そのもの**です。
訳が無ければ日本語のまま出るので、抜けは画面が壊れるのではなく混ざるだけ。
`npm run i18n:check` が抜けを挙げます。

## リプレイ

対戦が終わると自動で残ります。タイトル画面の **「リプレイ」** から。

動画ではありません。**種と、全員の押したキーと、機体だけ**です — この試合が
決定論的ロックステップで動いている以上、それだけで完全に再現できます。
4人対戦1分ぶんで数十KB（機体1機ぶんより小さい）。
